# ViixsDockerManager.DockLight.Environments

This project contains everything needed to create a new environment, on to which we want to connect and show things like the containers for a specific environment


Run `dotnet ef migrations add <MigrationName> --project ViixsDockerManager.DockLight.Environments --startup-project ViixsDockerManager.Server --context ViixsDockerManager.DockLight.Environments.DbContexts.DockLightEnvironmentWriteDbContext` to add a new migration for this project
